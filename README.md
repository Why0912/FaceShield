## 隐私与数据获取说明

由于人脸数据涉及隐私、安全与合规要求，**FaceShield 数据集不直接分发/包含任何可识别身份的人脸原始图片**。

为复现实验，数据集所涉及的图像可从以下三个原始公开数据集中自行获取（请务必遵守各自的许可协议、下载条款与使用限制）：

- **WMCA**
- **PADISI**
- **SiW-Mv2**

感谢 **WMCA**、**PADISI** 与 **SiW-Mv2** 数据集的作者与维护者为人脸活体检测研究提供的重要资源。
